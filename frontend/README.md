# NoteTag Frontend

Клиентское приложение для заметок на React, Vite и React Router.

## Запуск

```bash
npm ci
copy .env.example .env
npm run dev
```

После запуска откройте адрес, указанный Vite в терминале. В `.env` задайте адрес API через `VITE_API_URL`. Значение по умолчанию — `http://localhost:3000`. После изменения `.env` перезапустите приложение.

## Возможности

- Регистрация, вход и выход. Токен сессии хранится в `sessionStorage` и передаётся в защищённых запросах.
- Создание, просмотр, редактирование, удаление и поиск заметок; сортировка и фильтрация по тегам.
- Создание и удаление тегов, добавление и удаление тегов у заметок.
- Панель администратора со списком пользователей и общей статистикой.
- Адаптивный интерфейс для компьютера, планшета и телефона.

## Демо-режим

Для проверки интерфейса без API установите `VITE_DEMO_MODE=true` в `.env` и перезапустите приложение. В демо-режиме данные хранятся в браузере. Чтобы вернуться к работе с API, установите `VITE_DEMO_MODE=false`.

## Проверки

```bash

```
